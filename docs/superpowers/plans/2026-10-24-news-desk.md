# News Desk (Project 1) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Seven fictional reporters write short posts after each game, one article after each game night and at most one weekly piece, posted automatically to a new Discord channel and kept on a new `/news` section of the site.

**Architecture:** Migration 0071 adds the news tables and a per-player press level. A pure shared module `@eanhl/db/news` holds the reporters, the fact-sheet contract and the night/week keys. The web app builds fact sheets from the same loaders the match page uses and serves them on token-guarded internal routes; it also serves the public news pages and the admin tools. A **new `news` container** (same image as `discord`, its own entry point) polls the DB, fetches a fact sheet, asks the Claude API for structured JSON, checks it (numbers + names in code, quotes/events by a second Claude call), stores it, and posts through a second webhook with each reporter's name and picture.

**Tech Stack:** TypeScript strict, Drizzle + hand-written SQL, Next.js 15 (App Router, `next/og` for avatars), `@anthropic-ai/sdk`, Discord webhooks, `node:test`.

**Spec:** `docs/superpowers/specs/2026-10-24-news-desk-design.md` (characters: `docs/specs/news-personalities.md`)

## Global Constraints

- **Work in a git worktree** on branch `feat/news-desk` (superpowers:using-git-worktrees). The main checkout holds the operator's untracked design files (`*.html`, `SVG/`, `docs/cards/`, `apps/web/src/app/preview/`); never add them. A fresh worktree needs the steps in memory `project_fresh_worktree_prepush` before its first push. Pushing the new branch and merging to `main` need the operator's OK.
- **Isolation:** the news desk runs in its own container `news`. It never imports or changes `cycle.ts` / `cycle-unlocks.ts` / `index.ts` of the `discord` service, and the worker is not touched.
- **Model:** `claude-opus-5-5` (env `NEWS_MODEL`), `output_config.effort` `medium` for writing, `low` for the review call. Always `client.beta.messages.create` with `betas: ['server-side-fallback-2026-07-01']` and `fallbacks: 'default'`; check `stop_reason === 'refusal'` before reading content. `max_tokens` 16000. Structured output: `output_config: { format: { type: 'json_schema', schema } }`, then `JSON.parse` of the text block and a hand-written parser (no zod; the repo has none). No `temperature`/`top_p`/`top_k`, no `thinking` field.
- **Prices for cost records** (USD per 1M tokens, cached 2026-10-06 from the claude-api skill): `claude-opus-5-5` input 4.00, output 20.00, cache read 0.20, cache write 5.00; `claude-sonnet-5-5` 2.00 / 10.00 / 0.20 / 2.50; `claude-haiku-5-5` 0.10 / 0.50 / 0.01 / 0.125. Unknown model ⇒ use the Opus 5.5 row.
- **Money:** `NEWS_MONTHLY_LIMIT_USD` default `20`. The desk writes nothing new once this calendar month's (UTC) recorded spend is ≥ limit − 0.50. The Console workspace `boogeymen-news-desk` also has a $20 limit; the key lives in that workspace. Expected cost (Opus 5.5, write + review): about $0.07 per game and $0.12 per article ⇒ about $0.40 a night, about $5 a month at 8–9 nights. If the Console limit or the credits run out first, the API returns a 400; that is a normal job failure (3 tries, then skipped) — the design's "stop for the month" is met by the program's own limit, which is reached first.
- **Second check (design §7.1, builder's call):** a review call with the same model at effort `low` checks each item for invented quotes, invented events and personal criticism. Report this choice and its cost to the operator.
- **Test mode:** `NEWS_DRY_RUN` — anything but an explicit `0` is test mode (same rule as `DISCORD_DRY_RUN`). Test items get `is_test = true`, are written to `NEWS_OUT_DIR` as files, never sent, never shown publicly. On start in live mode the service deletes all `is_test` items.
- **Names:** a member is named only by `player_profiles.player_name`, or the gamertag when that is null/blank. Only members (`MEMBER_CONDITION`), never AI goalies (`ai_goalie_side is not null`), never guests or opponent players, never a player with press level `out`.
- **Press levels:** `'full' | 'easy' | 'out'`, column default `'full'` (operator: everyone starts at Full press). `press_level_set_by`: `'self' | 'admin' | null`.
- **Amounts:** after each counted game 1 post, or 2 when the situation is not `routine_win`/`quiet_win`; DNF ⇒ no posts. Post ≤ 280 characters. Night ends 90 min after its last game. Article body 250–450 words. Weekly piece: Mondays from 12:00 America/Edmonton, for the previous Monday–Sunday nights, only if that week had a game.
- **Night key:** `((played_at at time zone 'America/Edmonton') - interval '6 hours')::date`, as a `YYYY-MM-DD` string.
- **Frequency limits:** Dex Mercer ≤ 1 item per night and ≤ 3 items per 7 days; Father Rink ≤ 1 item per 14 days.
- **Site:** `/news` (lead + "More stories" rows, 10 per page, infinite scroll + button fallback; "The Wire" newest 20 posts + "Show older posts"), `/news/[slug]`, `/news/reporters/[reporter]`, nav link "News". Every `Link` to a data page has `prefetch`. Public queries always filter `is_test = false and deleted_at is null`.
- **Webhook messages:** `username` = reporter name, `avatar_url` = `${siteUrl}/news/avatar/<reporter id>`, `allowed_mentions: { parse: [] }`, all model text passed through `escapeMarkdown`. Reply prefix `↪ to <Name>: `. ≥ 2.1 s between sends.
- **Migrations:** hand-written idempotent SQL with the 0069 header form; applied with psql; drizzle journal stays frozen.
- **Gates:** `pnpm --filter <pkg> typecheck`, unit tests, `pnpm format`. Rebuild `@eanhl/db` (`pnpm --filter @eanhl/db build`) after any change in `packages/db/src`. `pnpm lint` is red repo-wide; do not chase it. DB SQL-pin tests run explicitly: `node --test packages/db/dist/queries/__tests__/<file>.test.js`.
- **Secrets:** `ANTHROPIC_API_KEY` and `NEWS_WEBHOOK_URL` only in the Hotel-Echo `.env`. The local key file `~/.config/eanhl/anthropic-news.key` is never printed, never committed. Error text never contains the webhook URL or the key.

## Review Focus

1. **A teammate with "Leave me out" who scores the winning goal** — their name is on no fact sheet, and an item that names them anyway is rejected. Pinned in Task 3 (`buildPeople` excludes `out` and lists the name in `forbiddenNames`) and Task 4 (`checkFacts` fails on a forbidden name).
2. **Number words and scores in prose** ("won 4–2", "three shots", "a 2-6 loss", "28.5%") — every number form is checked against the sheet, and a number the sheet does not have fails. Pinned in Task 4.
3. **The service restarts in the middle of a night** — no game is covered twice, the article is written once, and a job left `pending` by a crash is never re-picked. Pinned in Task 1 (claim SQL) and Task 6 (cycle tests).
4. **The Claude API is down, refuses, or the money limit is reached** — the job fails (retried up to 3 times) or waits; nothing is posted half-checked, and the game-result poster keeps working because it is another container. Pinned in Task 5 and Task 6.
5. **A deleted item** — it disappears from every public page at once, and its Discord message is deleted on the next pass, also after a restart. Pinned in Task 1 (public SQL filter) and Task 6 (delete pass).

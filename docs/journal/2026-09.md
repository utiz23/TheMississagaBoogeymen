**Same-day correction (E3J3B), after independent review — four boundary
defects fixed before E3J3 was considered complete:**

1. **Canonical local paths before containment comparison.** The config
   validator required paths to be absolute but not canonical, so
   `readback.dir = "/data/x/../artifacts/readback"` or
   `"/data//artifacts/readback"` passed the separation check while textually
   resolving inside `artifact.sourceDir = "/data/artifacts"`. Every local
   path field — `cli.executable`, `artifact.sourceDir`, `attestation.dir`,
   `readback.dir`, `run.lockFile`, and `capacity.backingVolume.mountPoint`
   when non-null — is now required to already be lexically canonical (no
   dot segments, no repeated/trailing separators); a non-canonical value is
   rejected outright, never normalized then compared. Documented as a
   LEXICAL guarantee only — it proves nothing about symlink/mount/filesystem
   aliasing, which remains deployment-time proof per memo §3.3. Whole-
   component behavior preserved: `/data/artifacts-2` is still not inside
   `/data/artifacts`.
2. **Artifact/attempt identity shape.** `buildPublishedObjectPaths()`
   accepted any ordinary-safe string as an `artifactBase` (e.g.
   `"not-a-stamped-artifact"`), and `formatAttemptId()` could return a
   malformed id (`"...Z-../BAD"`) if its injected `randomToken` boundary
   misbehaved. New `assertValidArtifactBase()` requires the exact
   `<artifactPrefix>-<YYYYMMDDTHHMMSSZ>` shape (prefix checked against
   `ARTIFACT_PREFIX_PATTERN`, stamp against `SNAPSHOT_STAMP_PATTERN`,
   correctly handling a prefix that itself ends in a hyphen); all three
   `build*` functions now call it in addition to the ordinary-component
   check. `formatAttemptId()` now validates its own constructed result
   before returning. `backup-producer.mjs`'s own `runId` construction is
   untouched.
3. **No secret-key echo.** `assertNoSecretShapedKeys()` included the
   offending key name in its `ConfigError` message — the key name itself may
   be the sensitive material. The message is now fully generic; only a
   stable error code (`config_secret_shaped_key`) is returned.
4. **Frozen `backingVolume`.** A non-null `capacity.backingVolume` was
   nested inside a frozen `capacity` object without itself being frozen
   (`Object.freeze()` is shallow). It is now frozen too.
